## 💡 Что такое PassGen?

Каждый раз придумывать новый сложный пароль вручную — не самая приятная
задача.

PassGen берёт её на себя.

Выбираете необходимые параметры, запускаете генерацию — и получаете
случайный пароль, который можно сразу скопировать и использовать.

Без лишних действий и без необходимости придумывать очередную комбинацию
из букв, цифр и символов.

---

## ✨ Что умеет PassGen?

### 🔑 Генерация паролей

Создавайте случайные пароли с нужным набором символов:

- 🔠 заглавные буквы;
- 🔡 строчные буквы;
- 🔢 цифры;
- 🔣 специальные символы.

Можно настроить параметры генерации под свои требования.

### 📏 Настройка длины

Нужен короткий пароль для тестового аккаунта?

Или длинный и максимально сложный?

Вы сами определяете параметры — PassGen создаёт пароль.

### 💪 Проверка надёжности

После генерации можно оценить сложность получившегося пароля.

Так проще понять, насколько выбранные параметры подходят для конкретной
задачи.

### 📋 Быстрое копирование

Получили пароль — скопировали — готово.

Не нужно выделять его вручную и переносить куда-то по частям.




### 🎲 Парольные фразы

В некоторых случаях парольную фразу использовать удобнее обычной
случайной последовательности символов.

Поэтому PassGen развивается и в этом направлении.

💾 Сохранение генераций

PassGen позволяет сохранять созданные генерации локально на устройстве.
Функция сохранения включается пользователем в настройках — если она отключена, новые генерации не сохраняются в истории.

Сохранённые данные можно:

📤 экспортировать в файл;

📥 импортировать обратно;

🗑️ удалить из истории.

## А что насчёт безопасности? 🤔

Безопасность — одна из главных идей проекта.

PassGen ориентирован на локальную генерацию паролей: создаваемые значения
не должны требовать отправки на сторонний сервер.

Иными словами, идея простая:

**создали пароль → скопировали → использовали.**

---

## 🛠️ На чём написан?

PassGen использует современный веб-стек:

- **Next.js** — основа приложения;
- **React** — интерфейс;
- **TypeScript** — логика и типизация;
- **Tailwind CSS** — стили;
- **pnpm** — управление зависимостями Node.js.

## 🚀 Запуск

Если хотите запустить PassGen локально, сначала клонируйте репозиторий:

```bash
git clone https://github.com/Anyusek/PassGen.git
cd PassGen
```
Установите зависимости:
```bash
pnpm install
```
Запустите проект:
```bash
pnpm dev
```
После запуска откройте:
```
http://localhost:3000
```
Если у вас не получается установить зависимости и запустить его, попробуйте другой вариант:
```bash
corepack pnpm install
corepack pnpm run dev
```
ВАЖНО: перед использованием убедитесь, что у вас установлен Node.js с версией 24 или новее.
